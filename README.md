## Запуск

Из каталога `frontend/dashboard-builder` с помощью python:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

## Языки интерфейса

Переключатель в шапке выбирает русский или английский язык. Выбор хранится в поле `locale` существующего сохранения localStorage. Старые сохранения без этого поля и неизвестные локали используют русский язык; виджеты сохраняются. Смена языка работает без перезагрузки, сохраняет черновики в полях и не переводит пользовательские заголовки и содержимое.

Переводы находятся в `js/locales/ru.js` и `js/locales/en.js`. Функция `t(key, params)` из `js/i18n.js` подставляет параметры вида `{count}`. Если перевод отсутствует, используется русский текст, а для неизвестного ключа — сам ключ. Статическая разметка переводится через `data-i18n`, атрибуты — через `data-i18n-aria-label` и `data-i18n-content`. Для добавления языка создайте такой же словарь, подключите его в `js/i18n.js` и добавьте пункт в `#locale-select`.

## Файлы

- `index.html` — семантическая разметка.
- `styles.css` — оформление, темы и адаптивность.
- `js/state.js` — создание виджетов, валидация, чтение и сохранение состояния.
- `js/i18n.js`, `js/locales/` — переключение языка и словари переводов.
- `js/ui.js` — небольшие DOM-помощники и уведомления.
- `js/modal.js` — модальные окна и управление фокусом.
- `js/widgets.js` — отображение и редактирование четырёх типов виджетов.
- `js/drag.js` — нативные Drag Events и touch-события.
- `js/app.js` — действия пользователя, порядок карточек и асинхронная загрузка.
