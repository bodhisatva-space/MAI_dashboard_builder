## Запуск

Из каталога `frontend/dashboard-builder` с помощью python:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

## Файлы

- `index.html` — семантическая разметка.
- `styles.css` — оформление, темы и адаптивность.
- `js/state.js` — создание виджетов, валидация, чтение и сохранение состояния.
- `js/i18n.js`, `js/locales/` — переключение языка и словари переводов.
- `js/ui.js` — небольшие DOM-помощники и уведомления.
- `js/modal.js` — модальные окна и управление фокусом.
- `js/widgets.js` — отображение и редактирование четырёх типов виджетов.
- `js/drag.js` — нативные Drag Events и touch-события.
- `js/app.js` — действия пользователя, порядок карточек и асинхронная загрузка.
